# Metric definitions and limitations

- **Cascade activity (0–100):** normalized descriptive indicator from the number of collected records in a text-similarity group and distinct observed sources. Not a measure of user reach, virality, or person-to-person transmission.
- **Source diversity / corroboration signal (0–100):** 25 points per distinct source, capped at 100. It does not assess source reliability, factual accuracy, or source independence. Several outlets may repeat one upstream report.
- **Credibility:** this release intentionally does not assign a truth score. A defensible future evidence module should store claims, supporting/contradicting/unclear evidence, provenance, source independence and human review.
- **Social impact:** requires domain, urgency, affected population, geographic relevance and engagement evidence. Current release collects source records but does not claim to measure real-world effects.
- **Growth prediction:** should only be enabled after enough regularly spaced historical observations exist. Current release displays observed history rather than inventing future values.
